# Handover Protocol

## Purpose

Create a fresh-session continuity artifact for a new agent session without hidden chat history.
It does not replace general project onboarding.

## Output Artifact

- target path: `adm/ops/reports/handover.md`
- artifact type: fresh-session live-state and continuity document

## Required Content (MUST)

1. document purpose
2. distinction between canonical onboarding and fresh-session continuity
3. current live state
4. current roadmap focus
5. current quality evidence
6. current risks and next actions
7. deterministic reboot reading order
8. tests and verification commands
