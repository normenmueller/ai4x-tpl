# Documentation Taxonomy Contract

## Purpose

Define the canonical documentation split for this project.

## Rules (MUST)

- `doc/usr/*` is direct human-facing documentation.
- `doc/agn/*` is agent-facing onboarding and routing.
- `doc/arc/*` is architecture and system-reference documentation.
- `adm/dev/*` is normative development governance.
- `adm/ops/*` is normative operations governance.
- `doc/*` explains; `adm/*` governs.
