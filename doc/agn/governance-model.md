# Governance Model

## Purpose

Explain the project's split between bootstrap, explanation, architecture, development governance, operations governance, and planning.

## Core Distinctions

- `AGENTS.md` = bootstrap contract
- `adm/dev/protocols/workflow.md` = development router
- `adm/dev/protocols/*` = task-specific execution protocols
- `doc/usr/*` = direct human-facing docs
- `doc/agn/*` = agent-facing onboarding and routing
- `doc/arc/*` = architecture reference docs
- `adm/dev/*` = development governance
- `adm/ops/*` = operations governance

## Documentation Consistency Rules

- descriptive docs stay in target-state voice
- governed text stays emoji-free
- `doc/*` explains and `adm/*` governs
