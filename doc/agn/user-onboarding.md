# User Onboarding

## Purpose

Use this document to explain the project quickly and route humans to the smallest fitting source.

## Canonical Sources

1. `doc/usr/primer.md`
2. `README.md`

## First-Answer Baseline

- explain what the project is
- explain that it is an ai4X-driven, minimal single-repo template for agent-first development and agent-guided documentation
- explain the source-layout split
- explain where human docs, agent docs, architecture docs, and governance live

## Routing Rule

If the human actually wants the full modular suite and reference implementation rather than the minimal bootstrap, route them to [ai4x](https://github.com/normenmueller/ai4x).
